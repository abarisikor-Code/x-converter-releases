# X-Converter · 문서 표준화 변환기

HWP · DOC · XLS · PPT 파일을 **HWPX · DOCX · XLSX · PPTX** 로 한꺼번에 바꿔 주는 Windows 프로그램입니다.
2026. 10. 1.(목)부터 JB메신저(대화·쪽지)에 비표준 문서 첨부가 제한되어 만들었습니다.

## 받기

[**최신 버전 내려받기 (Releases)**](https://github.com/abarisikor-Code/x-converter-releases/releases/latest)

zip 을 풀고 `x-converter.exe` 를 두 번 누르면 됩니다. 설치 없음 · 관리자 권한 필요 없음 · 무료.

## 사용법

1. 파일이나 폴더를 창에 끌어다 놓기 (여러 개 가능)
2. **[변환 시작]**
3. 열린 폴더에서 변환한 파일을 메신저 창에 끌어다 첨부

| 변환 | 쓰는 프로그램 |
|---|---|
| HWP → HWPX | 한컴오피스 한글 |
| DOC → DOCX | MS Word |
| XLS → XLSX | MS Excel · 없으면 한컴오피스 한셀 |
| PPT → PPTX | MS PowerPoint · 없으면 한컴오피스 한쇼 |

자세한 내용은 zip 안의 `X-Converter_사용안내.pdf` 를 보세요.
